# مدرسة معاذ

تطبيق جداول المعلمين وتوزيع حصص الاحتياط لمدرسة معاذ بن جبل للتعليم الأساسي (٥–١٢).

- **مدير المدرسة:** خميس العيسائي
- **تصميم البرنامج:** الأزهر الناعبي

## المزايا
- البحث عن أي معلم بالاسم وعرض جدوله الأسبوعي
- توزيع حصص الاحتياط تلقائياً بشكل عادل مع إمكانية التعديل اليدوي، ومشاركته عبر واتساب
- المعلمون المتفرغون في أي حصة، وجداول الفصول
- رابط مباشر لمنصة نور

## تنزيل التطبيق
ملف `maadh-school.apk` يُبنى تلقائياً عبر GitHub Actions من الفرع `maadh-school-app` ويظهر في قسم **Releases**.

صفحة الويب: `index.html`
