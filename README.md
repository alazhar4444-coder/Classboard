# رحلة داخل الفيروس — تطبيق أندرويد

تطبيق أندرويد يعرض صفحة HTML (`app/src/main/assets/index.html`) داخل WebView ويعمل بدون إنترنت.

## تنزيل التطبيق
كل دفع (push) إلى هذا الفرع يبني ملف APK تلقائياً عبر GitHub Actions وينشره في صفحة **Releases** باسم `VirusJourney.apk`.

## تحديث المحتوى
استبدل `app/src/main/assets/index.html` بالنسخة الجديدة وادفع التغيير — سيُبنى APK جديد تلقائياً.
